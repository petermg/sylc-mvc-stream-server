SyLC MVC Stream Server 0.7.0-alpha.3

Linux install or upgrade:

```bash
unzip SyLC-MVC-Stream-Server-0.7.0-alpha.3-source.zip
cd sylc-mvc-stream-server-0.7.0-alpha.3
chmod +x scripts/install.sh scripts/uninstall.sh engine/run-phase6-streaming-session.sh
sudo ./scripts/install.sh
```

The installer preserves the existing Media Libraries, state, service user, bind address,
port, encoder selection, VA-API device, and optional API-token hash.

After installation:

```bash
curl -fsS http://127.0.0.1:8097/api/health | python3 -m json.tool
sudo systemctl status sylc-mvc-stream --no-pager --full
```

Keep the previous `0.7.0-alpha.2` package available until the new public alpha has been exercised on the desired titles.
