# GitHub repository and release guide

Recommended repository name: `sylc-mvc-stream-server`

Recommended display name: **SyLC MVC Stream Server**

Recommended description:

> Self-hosted MVC 3D MKV and unencrypted Blu-ray 3D ISO streaming server with SBS, OU, single-eye, anaglyph, and passive 4K row-interleaved HLS output.

Recommended topics:

```text
3d-video mvc bluray hls ffmpeg vaapi self-hosted linux android-tv fire-tv
```

Initial release:

```text
Tag: v0.7.0-alpha.2
Title: SyLC MVC Stream Server 0.7.0-alpha.2
Type: Pre-release
```

Use `RELEASE_NOTES.md` as the release description. GitHub automatically supplies source archives for the tag. An exact project source ZIP and SHA-256 file may also be attached when desired.

After the Android repository exists, add its final URL near the top of `README.md`.
